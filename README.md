# 🚀 Pattern Generator! ✨

Welcome to the **Pattern Generator**, the most exciting way to create stunning geometric patterns and custom ASCII art in your browser! Whether you're a coding enthusiast, a math lover, or just someone who loves cool shapes, this tool is for you! 🌈

## 🌟 What can it do?

This project is all about bringing creativity to the console! You can generate a wide variety of patterns with just a few clicks:

### 📐 Geometric Magic
Choose from a library of classic shapes and watch them come to life!
- **Pyramids** 🔺
- **Squares & Rectangles** 🟦
- **Triangles** 📐
- **Diamonds** 💎
- **Hourglasses** ⏳
- **Hollow Squares** 🔲

### ✍️ Custom Creations
Want to see your own words or numbers turned into a pattern? Switch to **Custom Mode** and type whatever you like! It's your canvas—be as wild as you want! 🎨

### 🌓 Sleek Experience
Includes a beautiful **Light/Dark Mode** toggle so you can keep your eyes comfy while you create masterpieces, day or night! 🌙☀️

## 🛠️ How to Get Started

Getting this running is a piece of cake! 🍰

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/Marquee_project.git
   ```
2. **Open the magic:**
   Simply open `Pattern_Generator.html` in any modern web browser.
3. **Start Creating:**
   Pick a mode, enter your size or text, and hit **"Generate Pattern"**! 💥

## 🚀 Tech Stack

Built with a powerful and lightweight trio:
- **HTML5** for the structure 🏗️
- **CSS3** for the stunning visuals and dark mode 💅
- **JavaScript** for the pattern-generating brain 🧠
